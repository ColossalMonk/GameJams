# GameJams

This repository is a collection of projects, experiments, and notes related to game jams.

The goal of this project is to create and maintain a central place for game jam work, including prototypes, assets, and ideas that can be shared and improved over time.

## What this repository is for

- Organizing game jam projects in one place
- Tracking progress and versions of each jam entry
- Keeping notes, scripts, and assets together
- Building a reusable home for future game jam work

## Notes

This repo is intended to grow as more game jam projects are added and maintained.
