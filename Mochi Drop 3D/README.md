# Mochi Drop 3D

This folder contains a split version of the Mochi Drop game project.

## Structure

- index.html - main app markup and screen layout
- styles.css - visual styling, layout, and animation presentation
- script.js - game logic, rendering setup, input handling, and UI behavior

## Run locally

Open index.html in a browser, or serve the folder with a simple static server if you want to test it in a more realistic environment.

## Notes

This project is a polished, single-game jam prototype with a cute fruit-merge mechanic, animated UI, and a lightweight 3D presentation built with Three.js and GSAP.
